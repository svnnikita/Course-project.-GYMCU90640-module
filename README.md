## Course project on telemetry of Nikita Savin, student gr. 233 (2025). Program for STM32F3Discovery

**GYMCU90640 Thermal Imaging Module**

During the course project, the GYMCU90640 thermal imaging module and the STM32F3Discovery development board were used. The necessary hardware documentation is located in the [refs](https://github.com/svnnikita/thermal_imager/tree/main/refs) directory. Additional information on the module can be found in [this article](https://habr.com/ru/articles/435946/).

The first part of the course project is a program for STM32F3Discovery, which receives data from a sensor and forwards it to a computer for further processing. The second part of the project, a GUI for visually displaying the temperature, is located [here]().
